# News Implementation Plan

> Execution follows the user's supplied Qwen workflow: delegate specified routine code; orchestrator owns design, content validation, review, and publication.

**Goal:** Publish an easy-to-maintain News section for research and life updates.
**Architecture:** news.json renders into marked blocks in the static index.html. The existing hash router opens #news, and the homepage exposes the latest item.
**Tech Stack:** HTML/CSS/JS, Python standard library, existing Playwright suite and GitHub Pages workflow.
**Spec:** docs/superpowers/specs/2026-11-14-news-design.md

## Global constraints
- Preserve current content, Me, SEO, animation, themes, keyboard navigation, and five existing spatial destinations.
- New factual content only from user-supplied/existing facts; initial date precision is year 2026.
- No dependencies, backend, or artificial example news on the public site.

## Review focus
- Malformed dates/links and HTML-like text: generator tests.
- Empty feeds and same-date ordering: generator tests.
- News/latest-link placement on 320px and short landscape: browser geometry checks and screenshots.
- News direct route, focus return, no-JS content and motion: existing suite extended.
- CI must regenerate both during verification and deployment, not only locally.
